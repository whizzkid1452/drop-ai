# Coding Conventions

description: 코드 스타일 및 프로젝트 컨벤션 (toss/slash 기반)
globs: **/*.{ts,tsx,js,jsx}

---

## 공통 금지 조항

- 코드 주석, 커밋 메시지, 문서에 에이전트 이름/도구명/생성 서명을 남기지 않는다
- 예: `Made with Cursor`, `Generated by Claude`, `Authored by AI` 금지

# 코드 컨벤션

## 네이밍

| 대상 | 규칙 | 예시 |
|------|------|------|
| 변수 | camelCase, UPPER_CASE, PascalCase | `userName`, `MAX_RETRY`, `UserType` |
| 함수 | camelCase 또는 PascalCase | `fetchUser`, `CreateButton` |
| 인터페이스 | PascalCase | `UserProfile` |
| 타입 별칭 | PascalCase | `ButtonVariant` |
| 선행 언더스코어 | 변수에 한해 허용 | `_internalState` |

## 포매팅

- 들여쓰기: 2 spaces
- 줄 너비: 120자
- 따옴표: 작은따옴표 (`'`)
- 세미콜론: 필수
- 후행 콤마: ES5 스타일 (객체, 배열 마지막에 콤마)
- 줄 끝: LF
- 파일 끝 개행: 필수
- 화살표 함수 괄호: 인자 1개일 때 생략 (`x => x`)

## TypeScript

- `strict` 모드 사용
- `any` 타입 지양
- 미사용 변수/파라미터 금지 (`noUnusedLocals`, `noUnusedParameters`)
- 암묵적 반환 금지 (`noImplicitReturns`)
- switch fallthrough 금지 (`noFallthroughCasesInSwitch`)
- 배열 타입: 단순 타입은 `T[]`, 복합 타입은 `Array<T | U>`

## ESLint 핵심 규칙

- 암묵적 형변환 금지 (`no-implicit-coercion`)
- 항상 중괄호 사용 (`curly: all`)
- 엄격 동등 비교 (`===`, `!==`) — `null` 비교만 예외
- TODO/FIXME/XXX/BUG 주석은 warn 처리
- React hooks `exhaustive-deps` 필수
- import 정리: 저장 시 자동 정렬 (`organizeImports`)

## 커밋 메시지

```
<type>[optional scope]: <description>
```

### type

| type | 설명 |
|------|------|
| `feat` | 새로운 기능 |
| `fix` | 버그 수정 |
| `docs` | 문서 변경만 |
| `test` | 테스트 변경만 |
| `chore` | 그 외 (빌드, 설정 등) |

### scope

- 변경한 패키지 또는 함수명 (선택)
- 여러 패키지에 걸친 변경이면 생략 가능

### 예시

```
feat(useOverlay): add animation support
fix(ky): handle timeout error on retry
docs: update contributing guide
```

## PR 규칙

- 제목: `<type>[scope]: <description>`
- squash merge 사용 — 커밋 히스토리 스타일은 자유
- PR 본문에 Overview + Checklist 포함
- 필요 시 테스트, 문서 변경 포함

## 테스트

- 파일 위치: 대상 파일 옆에 `*.test.ts` 또는 `*.spec.ts`
- 환경: jsdom (Jest)
- 패턴: `**/*.{spec,test}.{js,jsx,ts,tsx}`, `**/__tests__/**`
- 외부 의존성은 Mock/Stub으로 격리
