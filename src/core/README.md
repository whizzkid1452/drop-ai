# Core Layer (도메인 계층)

이 디렉토리는 애플리케이션의 **도메인 모델**과 **비즈니스 로직**을 포함합니다.
이곳의 코드는 다음 원칙을 따릅니다:

- **순수 TypeScript**: React, Vue 등 프레임워크 의존성이 없어야 합니다.
- **인프라 무관 (Infrastructure Agnostic)**: Tone.js, LocalStorage 등 외부 서비스에 직접 의존하지 않습니다.
- **테스트 용이성**: 복잡한 브라우저 API 모킹 없이 단위 테스트가 가능해야 합니다.

## 모듈 구성

- `region/`: 오디오 리전 로직 (타이밍, 자르기, 길이 계산 등).
- `track/`: 트랙 관리 로직 (볼륨, 팬, 리전 컬렉션 관리).
- `session/`: 프로젝트 레벨 로직 (템포, 전역 제약 조건).
- `audio/`: 오디오 서비스 인터페이스 (Ports).
