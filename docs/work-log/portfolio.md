# Drop AI — 포트폴리오용 성과·과제 목록

`drop-ai`를 이력서·포트폴리오에 넣을 때 아래 카테고리(3.1~3.5)로 나눠 바로 활용할 수 있다. 개인 기여 범위에 맞게 항목을 선택해 사용한다.

---

## 프로젝트 한 줄

브라우저 기반 DAW에 CLI 제어와 온디바이스 LLM(WebLLM)을 결합해, 오디오 편집 명령을 자연어와 UI 양쪽에서 처리할 수 있도록 설계한 웹 오디오 애플리케이션.

---

## 기술 스택 (태그)

`React 19` · `TypeScript` · `Vite` · `Zustand` · `Tone.js` · `Web Audio API` · `@mlc-ai/web-llm` · `Web Worker` · `Vitest` · `Playwright` · `React Router` · `TanStack Query`

---

## 성과·과제 (카테고리별)

### 3.1 오디오 편집 UX·도메인

- **브라우저 DAW 기본 워크플로우 구현**: 재생·일시정지·정지·시크·루프·BPM·마스터 볼륨 제어를 하나의 컨트롤 플로우로 통합.
- **트랙/리전 편집 흐름 구축**: 트랙 추가/삭제, 리전 추가/이동/리사이즈/스플릿 등 핵심 편집 동작을 컨트롤러 레이어에서 일관되게 처리.
- **CLI + Web UI 동시 제어 모델**: 동일한 컨트롤러 인터페이스를 기반으로 인터랙션 채널을 확장할 수 있는 구조를 확보.

### 3.2 엔진·성능·브라우저 제약 대응

- **Tone.js 캡슐화 오디오 엔진**: 오디오 라이브러리 의존을 `AudioEngine` 내부로 제한해 상위 레이어 변경 비용을 절감.
- **Web Worker 기반 온디바이스 추론**: WebLLM 엔진 초기화를 워커로 분리해 메인 스레드 블로킹을 완화하고 로딩 진행률/실패 처리를 제공.
- **COOP/COEP 설정 적용**: 브라우저 오디오/워커 환경 제약을 고려해 개발·프리뷰 서버 헤더를 일관되게 관리.
- **성능 개선 포인트 식별**: 시간 표시 업데이트 주기 제어, 트랙 리스트 구독 세분화, 라우트 코드 스플리팅 등 실코드 기준 최적화 항목 도출.

### 3.3 상태·아키텍처 (핵심)

- **레이어드 아키텍처 고정**: `Apps → Controllers → Session/AudioEngine → Tone.js` 의존 방향을 강제해 변경 영향 범위를 제한.
- **Composition Root 도입**: `createApp`에서 객체 생성/주입을 단일화해 조립 책임과 비즈니스 책임을 분리.
- **Port & Adapter 적용**: `IAudioEngine` 인터페이스 중심으로 상위 모듈을 구현해 구현체 교체 가능성과 테스트 용이성 확보.
- **단방향 상태 흐름 유지**: UI는 Session을 읽기만 하고, 쓰기는 Controller만 수행하도록 규칙화해 상태 불일치 디버깅 비용을 낮춤.

### 3.4 DX·품질

- **단위/통합 테스트 자동화**: `Vitest`로 컨트롤러/레이어 핵심 로직의 회귀를 검증.
- **E2E 사용자 시나리오 검증**: `Playwright`로 재생, 루프, 파일 업로드, 리전 조작, 내보내기 흐름을 자동화.
- **타입 안정성 유지**: Session/Controller/Engine 경계 타입을 명확히 해 기능 확장 시 안전한 리팩토링 기반 확보.

### 3.5 이력서·소개문 키워드

- **브라우저 DAW 아키텍처 설계**
- **온디바이스 AI 명령 파싱(WebLLM + Worker)**
- **Audio Engine 추상화와 상태 일관성 제어**
- **테스트 기반 회귀 방지(Vitest + Playwright)**

## 부록: 기술 과제(도전 과제) — 선택

면접·서술형 답변에서 상황에 맞춰 선택해서 사용한다.

- **상태 동기화 난이도**: 오디오 엔진 시간축과 UI 상태를 일치시키기 위한 단일 업데이트 경로 설계.
- **메모리 관리 과제**: 오디오 파일 로딩 과정의 Object URL/버퍼 수명 관리 정책 정립 필요.
- **렌더링 최적화 과제**: 빈번한 시간 업데이트와 트랙 리스트 구독 구조에서 불필요한 리렌더 제거.
- **초기 로딩 최적화 과제**: 라우트/기능 단위 코드 분할로 번들 크기와 초기 로드 비용 최소화.
