# 채팅 명령 목록

## 결론

현재 `AudioCommand`에는 29개 명령이 정의되어 있고, 29개 모두 실행기에 연결되어 있다.

하지만 구현된 기능을 모두 채팅에서 사용할 수 있는 것은 아니다.

- 채팅에서 조건부로 실행 가능한 명령: 28개
- 채팅 정책상 비활성화된 명령: `ADD_TRACK` 1개
- 새 오디오 파일 가져오기: 채팅에서 불가능
- 저장된 프로젝트 검색: 채팅에서 불가능

채팅은 일반 대화형 도우미가 아니라 사용자의 자연어 요청을 `AudioCommand`로 변환하는 명령 인터페이스다.

## 사용 방법

명령 이름이나 JSON을 직접 입력할 필요는 없다. 채팅에 자연어로 요청하면 된다.

```text
첫 번째 트랙 볼륨을 80%로 설정해줘
```

채팅은 현재 화면에 전달된 Track, Region, Plugin 정보를 기준으로 대상을 찾는다. 대상을 안전하게 식별할 수 없으면
명령을 실행하지 않는다.

## Web 편집기 단축키

Windows와 Linux에서는 `Ctrl`, macOS에서는 `⌘`를 사용한다.

### 재생과 탐색

| 단축키                | 동작                                                              |
| --------------------- | ----------------------------------------------------------------- |
| `Space`               | 정지 또는 일시정지 상태에서는 재생하고, 재생 중에는 일시정지한다. |
| `Shift+Space`         | 재생을 정지하고 재생 위치를 0초로 옮긴다.                         |
| `Home`                | 재생 위치를 0초로 옮긴다.                                         |
| `←` / `→`             | 재생 위치를 1초 이전 또는 이후로 옮긴다.                          |
| `Shift+←` / `Shift+→` | 재생 위치를 5초 이전 또는 이후로 옮긴다.                          |

### 편집과 프로젝트

| 단축키                       | 동작                                                |
| ---------------------------- | --------------------------------------------------- |
| `Ctrl/⌘+Z`                   | 마지막 편집을 실행 취소한다.                        |
| `Ctrl/⌘+Shift+Z`, `Ctrl/⌘+Y` | 취소한 편집을 다시 실행한다.                        |
| `Ctrl/⌘+S`                   | 현재 프로젝트와 등록된 오디오 원본을 저장한다.      |
| `Ctrl/⌘+O`                   | 프로젝트 목록에서 현재 선택한 프로젝트를 불러온다.  |
| `Ctrl/⌘+Shift+O`             | 저장된 프로젝트 목록을 새로고침한다.                |
| `Ctrl/⌘+Shift+E`             | 현재 범위 또는 전체 프로젝트를 WAV 파일로 내보낸다. |
| `Esc`                        | 선택된 내보내기 범위를 해제한다.                    |

### 화면

| 단축키      | 동작                                         |
| ----------- | -------------------------------------------- |
| `` ` ``     | Terminal 패널을 열거나 닫는다.               |
| `I`         | Track Inspector 패널을 열거나 닫는다.        |
| `+` / `-`   | 타임라인을 확대하거나 축소한다.              |
| `0`         | 타임라인 배율을 기본값인 20 px/s로 되돌린다. |
| `Ctrl/⌘+휠` | 타임라인을 확대하거나 축소한다.              |

입력창, 선택 상자, 버튼, 링크 또는 `contenteditable` 요소에 초점이 있으면 전역 단축키를 실행하지 않는다. 이 규칙은
텍스트 입력과 각 컨트롤의 기본 키보드 동작을 보존한다.

Track과 Region을 대상으로 하는 삭제, Mute, Solo, 분할 단축키는 현재 없다. Session에 선택된 Track 또는 Region을 나타내는
상태가 없으므로 전역 키 입력만으로 변경 대상을 명확히 결정할 수 없기 때문이다.

## 재생 명령

| 명령               | 자연어 예시                 | 동작                                      |
| ------------------ | --------------------------- | ----------------------------------------- |
| `PLAY`             | `재생해줘`                  | 현재 위치부터 재생한다.                   |
| `PAUSE`            | `일시정지해줘`              | 현재 위치에서 일시정지한다.               |
| `STOP`             | `정지해줘`                  | 재생을 정지하고 재생 위치를 0초로 옮긴다. |
| `SET_CURRENT_TIME` | `재생 위치를 30초로 옮겨줘` | 재생 위치를 지정한 절대 시간으로 옮긴다.  |

## 프로젝트와 편집 명령

| 명령                | 자연어 예시                        | 조건 또는 동작                                                                  |
| ------------------- | ---------------------------------- | ------------------------------------------------------------------------------- |
| `UNDO`              | `마지막 편집 취소해줘`             | 실행 취소가 가능한 편집이 있어야 한다. 다른 명령과 함께 실행하지 않는다.        |
| `REDO`              | `방금 취소한 편집 다시 실행해줘`   | 다시 실행할 편집이 있어야 한다. 다른 명령과 함께 실행하지 않는다.               |
| `SET_TEMPO`         | `템포를 128로 설정해줘`            | 0보다 큰 값을 사용한다. 현재 구현은 tempo 메타데이터를 변경한다.                |
| `SET_MASTER_VOLUME` | `전체 볼륨을 40%로 설정해줘`       | 입력 범위는 0%부터 100%까지다.                                                  |
| `SAVE_PROJECT`      | `현재 프로젝트 저장해줘`           | 현재 프로젝트와 등록된 오디오 원본을 저장한다.                                  |
| `LOAD_PROJECT`      | `<Project UUID> 프로젝트 불러와줘` | 사용자가 정확한 Project UUID를 입력해야 한다. 다른 명령과 함께 실행하지 않는다. |

## Track 명령

| 명령               | 자연어 예시                               | 조건 또는 동작                                                                 |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------------------------ |
| `REMOVE_TRACK`     | `두 번째 트랙을 삭제해줘`                 | 현재 채팅 정보에 표시된 Track만 제거할 수 있다. 포함된 Region도 함께 제거된다. |
| `SET_TRACK_NAME`   | `첫 번째 트랙 이름을 Lead Vocal로 바꿔줘` | 이름은 공백이 아닌 1자 이상 255자 이하여야 한다.                               |
| `SET_TRACK_VOLUME` | `첫 번째 트랙 볼륨을 80%로 설정해줘`      | 입력 범위는 0%부터 100%까지다.                                                 |
| `SET_TRACK_PAN`    | `첫 번째 트랙을 왼쪽 50%로 옮겨줘`        | 왼쪽은 음수, 가운데는 0, 오른쪽은 양수로 처리한다.                             |
| `SET_TRACK_MUTE`   | `첫 번째 트랙을 음소거해줘`               | 지정한 Track의 mute 상태를 변경한다.                                           |
| `SET_TRACK_SOLO`   | `첫 번째 트랙만 솔로로 들어볼게`          | 지정한 Track의 solo 상태를 변경한다.                                           |

## Region 명령

| 명령            | 자연어 예시                                  | 조건 또는 동작                                                                                            |
| --------------- | -------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `LOAD_REGION`   | `첫 번째 Region 소스를 20초 위치에 복제해줘` | 첫 번째 Region의 오디오 소스가 사용 가능한 경우에만 같은 소스를 복제할 수 있다. 새 파일은 가져올 수 없다. |
| `UNLOAD_REGION` | `첫 번째 Region을 삭제해줘`                  | 현재 채팅 정보에 표시된 Track과 Region만 지정할 수 있다.                                                  |
| `SPLIT_REGION`  | `첫 번째 Region을 10초에서 분할해줘`         | 분할 시간은 프로젝트 기준 절대 시간이며 Region 내부여야 한다.                                             |
| `MOVE_REGION`   | `첫 번째 Region을 15초 위치로 옮겨줘`        | Region의 시작 시간을 지정한 절대 시간으로 변경한다.                                                       |

## Plugin 명령

| 명령                   | 자연어 예시                                | 조건 또는 동작                                                |
| ---------------------- | ------------------------------------------ | ------------------------------------------------------------- |
| `INSTALL_PLUGIN`       | `첫 번째 트랙에 Gain Plugin을 설치해줘`    | 현재 Plugin catalog에 표시된 Plugin만 설치할 수 있다.         |
| `REMOVE_PLUGIN`        | `첫 번째 트랙의 Gain Plugin을 제거해줘`    | 현재 채팅 정보에 표시된 Plugin instance만 제거할 수 있다.     |
| `MOVE_PLUGIN`          | `Gain Plugin을 두 번째 처리 순서로 옮겨줘` | 같은 Track에 표시된 Plugin 처리 순서 안에서만 이동할 수 있다. |
| `SET_PLUGIN_ENABLED`   | `첫 번째 트랙의 Gain Plugin을 꺼줘`        | 현재 채팅 정보에 표시된 Plugin instance만 변경할 수 있다.     |
| `SET_PLUGIN_PARAMETER` | `Gain Plugin의 gain을 0.5로 설정해줘`      | Parameter 타입과 허용 범위를 지켜야 한다.                     |

## 내보내기 명령

| 명령                 | 자연어 예시                                    | 조건 또는 동작                                                     |
| -------------------- | ---------------------------------------------- | ------------------------------------------------------------------ |
| `SET_EXPORT_RANGE`   | `3초부터 10초까지 내보내기 범위로 설정해줘`    | 시작 시간은 0 이상이고 종료 시간은 시작 시간보다 커야 한다.        |
| `CLEAR_EXPORT_RANGE` | `내보내기 범위를 해제해줘`                     | 선택된 내보내기 범위를 해제한다.                                   |
| `EXPORT_AUDIO`       | `현재 프로젝트를 result 이름의 WAV로 내보내줘` | 선택 범위가 있으면 해당 범위를, 없으면 전체를 WAV 파일로 내보낸다. |

범위를 지정하고 즉시 내보내는 요청도 가능하다.

```text
3초부터 10초까지 WAV로 내보내줘
```

이 요청은 `SET_EXPORT_RANGE`, `EXPORT_AUDIO` 순서로 실행된다.

## 채팅에서 사용할 수 없는 기능

### 새 Track 추가

`ADD_TRACK`은 스키마와 실행기에 구현되어 있지만 채팅에서는 사용하지 않도록 설정되어 있다. 새 Track ID를 채팅 모델이
임의로 생성하지 못하게 막았기 때문이다.

### 새 오디오 파일 가져오기

브라우저에서 사용자가 선택하거나 드롭한 로컬 파일이 필요하므로 채팅만으로 실행할 수 없다. `LOAD_REGION`은 이미 등록된 첫
번째 Region의 오디오 소스를 복제할 때만 사용할 수 있다.

### 저장된 프로젝트 검색

저장된 프로젝트 목록은 채팅 입력 정보에 포함되지 않는다. 따라서 채팅으로 프로젝트를 검색하거나 이름으로 불러올 수 없고,
사용자가 정확한 Project UUID를 입력한 경우에만 `LOAD_PROJECT`를 실행할 수 있다.

### 일반 질의응답

현재 채팅은 DAW 명령 생성 전용이다. 인사, 설명 요청, 지원하지 않는 요청에는 실행할 명령이 없다는 의미의 빈 명령 배열을
반환한다.

## 현재 제한

- Track과 Region 정보는 최대 1,600자까지만 채팅 모델에 전달된다.
- Plugin 정보는 최대 1,200자까지만 채팅 모델에 전달된다.
- 목록이 잘리면 뒤쪽 Track, Region, Plugin을 이름이나 순번으로 안전하게 지정하지 못할 수 있다.
- 명령 지원은 실행 가능 경로가 있다는 뜻이다. 현재 프로젝트 상태나 입력값이 조건을 만족하지 않으면 실행 단계에서 실패할 수
  있다.
- 화면의 Quick Guide에는 `Play`, `Set Export Range`, `Adjust Volume`, `Adjust Panning`만 표시되지만, 실제 지원 범위는
  이 문서의 28개 명령이다.
